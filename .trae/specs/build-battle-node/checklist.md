# Checklist

> V0.1 极简竖切验收清单。未通过则回到 `tasks.md` 增补任务。

## 配置与架构

- [x] 7 个 JSON 存在且带 `schemaVersion`
- [x] 所有 id 唯一，引用无断裂
- [x] 故意破坏引用时启动报错并给出字段路径
- [x] 修改面板键位配置后按钮布局同步变化
- [x] `src/game/` 无 DOM 引用、无 `ui/` 依赖
- [x] 仅 `BattleModule` 对外暴露
- [x] 业务数值无硬编码，随机数全部来自注入 `Rng`

## 战斗规则

- [x] 阶段顺序为 `BOSS_INTENT → PLAYER_PLANNING → PRE_CHECK → SETTLEMENT → TURN_END`
- [x] 结算为 Boss 先行交替，一方耗尽后另一方继续
- [x] 玩家杀气 ≤ 0 跳过当前操作并回满，每回合仅 1 次
- [x] 二次归零跳过本回合剩余耗气操作
- [x] Boss 杀气不每回合回满，归零后下回合轮空并回满
- [x] 防御时 Boss 削减 0.5 / 1.0，反弹 1.0 / 2.0
- [x] 基础连招额外削 4 杀气、伤害 ×1.1
- [x] 插入防御 / 药品 / 切换后断连
- [x] `interruptOn` 置空后不断连，且无需改代码
- [x] Boss 阶段权重：HP > 50 为 70/30，HP ≤ 50 为 40/60
- [x] 特殊武器只有普攻，`3.1 / 3.2` 常驻
- [x] 特殊攻击次数全局共享，战斗内不恢复
- [x] 药品次数按 `items.json` 扣减

## 指令与面板

- [x] 入队即快照，切换面板不改变已入队指令
- [x] 撤回为 LIFO，撤回唯一 switch 后面板回退
- [x] 切换后执行 2 个操作才能再切，冷却跨回合
- [x] 杀气累计预扣，超发按钮置灰
- [x] 置灰按钮不可点击、不可入队

## 界面与演出

- [x] 所有数值显示 1 位小数
- [x] 375px 宽无横向滚动，按钮点击区 ≥ 44px
- [x] 血条 / 杀气条向左削减且有过渡
- [x] 玩家序列与 Boss 意图可见
- [x] 行动方高亮、对方变暗、当前图标闪烁
- [x] 受击白闪生效，且不阻塞逻辑
