# 战斗规则（唯一事实源）

> 改数值只改 `config/`；改规则必须先改本文件，再改代码。

## 1. 基础数值

| 对象 | 血量 | 杀气 |
|---|---|---|
| 玩家 | 50 | 10 |
| Boss | 100 | 30 |

## 2. 武器

格式：耗杀气 / 伤害 / 削 Boss 杀气。

| 武器 | 类别 | 面板按钮 | 普攻 | 特殊攻击 |
|---|---|---|---|---|
| 单手剑 | 普通 | 1.1 / 1.2 | 1 / 5 / 1 | 2 / 7 / 2 |
| 双手剑 | 普通 | 2.1 / 2.2 | 2 / 7 / 3 | 3 / 10 / 5 |
| 巨斧 | 特殊 | 3.1 | 3 / 9 / 2 | 无 |
| 弓箭 | 特殊 | 3.2 | 1 / 3 / 2 | 无 |

- **特殊武器只有普攻**，不参与需要“特殊攻击”的连招。
- 特殊武器面板按钮常驻显示，与两把普通武器分区。

## 3. 回合状态机

```
BOSS_INTENT → PLAYER_PLANNING → PRE_CHECK → SETTLEMENT → TURN_END
                                                        ↘ BREAK_TURN / BATTLE_END
```

- `BOSS_INTENT`：按阶段权重随机生成 2~3 条意图并公开。
- `PLAYER_PLANNING`：排布、撤回、切换，受杀气与次数限制。
- `PRE_CHECK`：双方连招判定、Boss 特殊效果判定，标记加成落点。
- `SETTLEMENT`：Boss 先行交替结算（Boss1 → Player1 → Boss2 → Player2 …）。
- 一方操作耗尽即停止行动并等待，另一方继续执行剩余操作。
- `TURN_END`：玩家杀气回满、切换冷却递减、Buff 计时、回合数 +1。

## 4. 杀气

- 玩家每回合开始回满 10.0。
- **杀气 ≤ 0 视为归零**；余额不足以支付当前操作同样按归零处理。
- 归零 → 跳过当前操作 → 立刻回满（**每回合限 1 次**）；再次归零 → 跳过本回合剩余耗杀气操作，下回合恢复。
- Boss 杀气 30.0，不每回合回满，损耗永久保留。
- Boss 归零 → 跳过本回合剩余操作 → 下回合整回合轮空（显示“破防中”，玩家正常输出）→ 轮空结束回满。
- Boss 普攻削玩家杀气 1.0，特殊削 2.0。
- 所有杀气内部按 1 位小数收敛，显示 1 位小数。

## 5. 防御

- 0 耗杀气，成功格挡配对操作时**受到的伤害减半**，最终数值 `round1`。
- 减伤系数由 `battle.config.json.defense.damageScale` 配置（默认 0.5），代码中不得写死。
- 减半后的伤害仍可致死；结算后照常判定战斗胜负。
- Boss 对玩家的杀气削减减半：普攻 1 → **0.5**，特殊 2 → **1.0**，不取整。
- 反弹给 Boss 的是**原削减量**（1.0 / 2.0）。

## 6. 连招

- 基础连招：`普攻 → 特殊 → 普攻`，额外削 Boss 杀气 4，伤害 ×1.1。
- 加成作用于 pattern 最后一个操作。
- 仅同一回合内连续操作有效；插入 `defend / item / switch` 即断连并重新计数。
- 预留扩展：`interruptOn` 可改为空数组、`breakMode: reset | ignore`、`match.consecutive: true | false`，实现“不断连”时只改配置。

## 7. Boss AI

- 每回合操作数 2~3 条随机。
- 阶段划分：HP > 50 为第一阶段（普攻 70% / 特殊 30%）；HP ≤ 50 为第二阶段（普攻 40% / 特殊 60%）。
- 排序随机，按权重抽取，同一回合内可重复。
- Boss 攻击伤害占位：普攻 6、特殊 10（可调）。
- 无尽模式按层数缩放：`effective = base × (1 + perFloor × (floor - 1))`，结果 `round1`，字段见 `SCHEMA.md` §3.5。

## 8. 指令与面板

| 按钮 | 含义 |
|---|---|
| 1.1 / 1.2 | 第一把普通武器：普攻 / 特殊 |
| 2.1 / 2.2 | 第二把普通武器：普攻 / 特殊 |
| 切换 | 仅在第一把与第二把普通武器之间互换，只改面板 |
| 3.1 / 3.2 | 巨斧 / 弓箭（常驻，仅普攻） |
| 4.1 / 4.2 | 药品 |
| 格挡 | 独立按钮 |

- 玩家序列为 LIFO 栈，撤回移除最右侧一条。
- 撤回后若序列中仍有切换指令，面板保持新武器；切换指令被撤回则面板立即回退。
- 切换为独立入队操作，0 耗杀气；切换后再执行 2 个操作才能再次切换，冷却跨回合保留。
- 进战后不可更换装备。
- 入队瞬间生成快照（伤害、耗杀气、武器 ID、剩余次数），已入队指令不受面板变化影响；结算只读快照。
- 排布阶段：杀气不足或次数耗尽时按钮置灰。
- 排布期按队列内已入队攻击的耗杀气**累计预扣**，累计值超过当前杀气即置灰，不允许超发。
- 面板顺序由 `baseOrder` 逐条应用队列中的切换指令推导；撤回切换指令时面板自动回退，不额外保存面板状态。
- 切换冷却从**实际执行**该切换操作时开始计数；撤回与因归零被跳过的操作均不计入。

## 9. 特殊攻击次数

- 全局共享一个次数池，初始 3 次，Battle 内不恢复。
- 仅普通武器（单手剑 / 双手剑）的特殊攻击消耗该池。
- 次数耗尽后所有特殊攻击按钮置灰。

## 10. 结算要点

- 伤害、杀气、反弹、连招加成的计算顺序在 `data_rules.md` 中定义。
- 所有最终数值 `round1`，显示 `toFixed(1)`。
